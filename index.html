Annotation handbook

Manipulation Annotation Handbook

How to mark up every act of manipulation in a video: who touched what, when they touched it, and what they were trying to do.

You will work through a list of short videos: kitchens filmed from the wearer's head, robot arms on a bench, hands assembling things. For each one you produce two things: the masks that say where each actor (a human hand, a parallel gripper, or a dexterous hand) and each manipulated object is in every frame, and the timeline that says when each manipulation started, when contact happened, and when the actor let go.

A tracking model does the tedious part, but only after you point it at the right thing, and you always have to check what it produced.

In stage ① Grounding you draw a starting box around each entity (the actor, and the object it is manipulating), and SAM3 propagates that box into a mask for every frame of the clip. Then you inspect what came back and repair it with the editing tools: extend a track that stopped early, subtract a mask that has leaked onto a neighbouring object, delete one that jumped onto the wrong thing entirely.

In stage ② Action segmentation you read the timeline instead: when did a manipulation start, what is the actor actually doing, and when did it end. Camera motion makes this harder than it sounds. In a lot of footage the shot swings onto the scene when the actor is already holding the tool, so the reach and the grasp were simply never filmed. That is a normal thing to encounter, and the tool has an explicit field for it. Record what the video shows.

The one habit that matters

When you did not see something, say so. Do not guess a frame number. The tool has an explicit option for every "never filmed" case, and a marked-as-unobserved boundary is worth more than an invented one. Inventing frame numbers is the single most damaging thing you can do to this dataset.

01Get connected

The tool runs on a lab server that is not reachable from the internet. You forward one port over SSH and then open it in your own browser. The SSH window stays open while you annotate. Closing it drops the connection.

  1. Add the server to your SSH config

    Open ~/.ssh/config (on Windows, C:\Users\<you>\.ssh\config) and add:

    Host nlplab1
    HostName <jump host address, ask Professor Huang>
    User <your account>

Host nlplab2
    HostName nlplab2
    User <your account>
    ProxyJump nlplab1

    The server sits behind a jump host, which is what ProxyJump handles. Check it works: ssh nlplab2 should log you in. Type exit to come back.

  2. Open the tunnel

    ssh -L 18990:localhost:18990 nlplab2

    Leave this window open. If port 18990 is already taken on your machine, map a different one, such as ssh -L 8080:localhost:18990 nlplab2, and use that number in the next step.

  3. Open the tool and sign in

    Go to http://localhost:18990 and sign in with the account you were given. Each video is assigned to exactly one person, so you will never collide with anyone else's work.

If the page will not load

Look at the SSH window first. That is where the failure shows up. ssh -v nlplab2 prints each hop, so you can tell whether the jump host or the server is refusing you.

02Your task list

The first page is your queue. Every row is one video and carries two ticks, one per stage. You must finish stage ① Grounding before stage ② Action segmentation unlocks.

Three things in that table are worth naming.

MarkWhat it is
1 The video id, in blue. Click it to open that video and start work.
2 ① Grounding. A green tick means the stage already holds annotation; a grey box means it is still empty.
3 ② Action. Same again for the action stage.
A tick does not mean the video is finished

The tick only says that the stage contains annotation the tool considers self-consistent: the required fields are filled in and nothing contradicts anything else. It says nothing about whether the annotation is complete. Objects that were manipulated can still be missing, and actions that happen in the video can still be unrecorded.

So the tick is not your finish line. When you think a video is done, watch it through once more and ask whether everything that happens in it is actually recorded. You are the only check on that.

Progress saves itself as you go: every edit reaches the server straight away, and text you type is stored about half a second after you stop typing. Unfinished only hides what you have already completed, and the page remembers where you had scrolled to when you come back from a video.

03What you are recording

Four words carry the whole model. They nest inside each other.

TermWhat it is
Clip A stretch of time where manipulation is happening. You cut the video into clips so that tracking only runs where it is needed. A quiet video can be one clip covering everything.
Entity Something you draw a box around: an actor (the thing that does the manipulating, which is always a human hand, a parallel gripper, or a dexterous hand), an object being manipulated, or a part of an object (a handle, a lid).
Episode One continuous manipulation of one object by one holder: reach for it, touch it, do something with it, let go.
Action A slice of an episode with a single purpose. Holding a knife for 18 seconds is one episode; scooping, spreading, and putting the cheese back are three actions inside it.

The six marks

An episode is stored as six frame numbers. The coloured phases you see on the timeline are all derived from them; you never draw the bands directly.

free hand reach grasp manipulating still holding unknown (actor not visible)

Two shortcuts the tool takes for you. If an episode is not a grasp (a press, a tap, a push on a lid), then reach end, contact and manip. start are the same frame, and the tool locks them together so you only set one. And if you never saw the moment of contact, you leave A, B and C empty and say why; the tool then greys those boxes out entirely.

04Stage ① Grounding

Here you produce the masks. The running example is a kitchen video: someone opens a drawer, takes out a pair of tongs, and uses them to move bread onto a plate.

  1. Watch it first

    Tick Preview mode and play the whole video. You cannot cut sensible clips until you know what happens. Untick it when you are ready to draw, because the canvas takes over the mouse for boxes.

  2. Cut the clips

    Pause where a manipulation begins and click [ Start; pause where it ends and click ] End; then ＋ Create clip. In the example, opening the drawer and picking up the tongs is one clip, f44–f79.

    A clip should cover one bout of activity. Do not try to make them perfect. Boundaries are adjustable in the sense that you can delete a clip and cut it again, though that deletes the work inside it.

  3. Register the entities

    Pause on a frame where your target is clearly and completely visible, then drag a tight box around it. When you release the mouse, say what it is: an actor (and which hand), an object (give it a plain English name like kitchen tong), or a part of something already registered.

    Draw every box you need on the same frame, then hit Start tracking. Boxes from one frame propagate together, so five cost about as much time as one. The model tracks forwards and backwards to fill the clip.

    Naming

    Use the same name for the same thing across clips, because the tool uses matching names to remind you to merge them later. kitchen tong in clip 1 and kitchen tong in clip 2 is what you want; tongs and tong is not.

  4. Check the tracking

    Play it back with the mask overlay on. When the model drifts onto the wrong object or the mask collapses, the Issues panel flags it: area cliffs, sudden growth, loss, position jumps, and masks that overlap each other.

    Fixes, roughly in order of how often you will need them: Re-box → replace this frame onwards when it jumped to the wrong thing; ＋ Add / － Subtract to patch a region; 🧹 Clean up stray blobs when scraps are left over.

  5. Merge the same thing across clips

    Each clip registers its own entities, so the same right hand becomes actor2, actor3, actor4… Use 🔗 Merge to join them into one identity. In the example the tongs appear in clips 1–5 and become a single entity.

    Order matters

    Merge parents before parts. Two handles cannot be merged until the two doors they belong to are one entity. The tool blocks it and tells you why.

05Stage ② Action segmentation

Now you say what happened. Open the video and switch to ② Action segmentation. If the video has several clips, the tool first asks you to confirm that you merged identities across them, and lists anything suspicious it found.

Each clip gets one track per holder: one for each hand. The object being manipulated does not get its own track. It goes in the episode's Object field.

What auto-fill gives you

The tool proposes episodes by looking at where masks touch and move together, and fills in marks where it can. Treat it as a first draft: it is good at spotting that something happened and rough about exactly when.

In clip 1 of the example it produces two tracks:

TrackObjectAB CDendBoundary
left handdrawer unitn/an/a n/a4470 already in contact when it starts
right handkitchen tong6869 747579observed

The left hand is already on the drawer in the first frame of the clip, so its reach and contact were never filmed, so the boundary is marked as unobserved and A, B and C stay empty. The right hand's reach for the tongs happens on camera, so all six marks are real.

Correcting a mark

Select an episode by clicking its band on the track. The editor scrolls to that episode and highlights it. Then, for each mark: park the playhead on the right frame and click Use current frame, or nudge with −1 / +1, or type the number. With an episode selected, A B C D E set the corresponding mark to the current frame.

Step frame by frame with ← → to find contact exactly. This is the frame worth being slow about.

Saying what you did not see

Every episode has two boundary questions. Answer them honestly. This is the habit from the top of this page, made concrete.

Start of the episodeMeans
Observed: you can see the reach and the contactNormal. Fill in A, B, C.
Already in contact when the episode starts The hand was on the object from the first frame you can see. A, B, C are greyed out.
The moment of contact was occluded You watched the hand approach, then something blocked the view, and by the time you could see again it was touching.
Why it endedMeans
Normal releaseYou saw the hand let go. Fill in the release frame.
Cut short: actor left the frame or the camera moved The episode was still going when you lost sight of it. Release stays empty.
The moment of release was occludedSame, but blocked rather than out of frame.

When you choose one of the "not observed" options, the tool greys out the corresponding frame boxes and stores them as empty. Any number you had typed stays on screen for reference but is not written to the file.

Splitting an episode into actions

If the purpose changes while the object is still held, cut it: park the playhead and click Split at the current frame (or press S). Give each slice a skill and a one-line description.

The clearest example in this video is the knife: one episode from picking it up to putting it down, cut into five actions: pick up the knife, scoop out the cheese, spread it on the bread, spread again, put the cheese back.

06Tools: when an object manipulates another object

This is the case people get wrong, so it gets its own section. In the example the person picks up a pair of tongs and uses them to move bread. The tongs are being held by a hand and are holding the bread.

You record it as two layers. The hand's track says it is manipulating the tongs. Then the tongs get a tool track of their own, saying they are manipulating the bread.

How to get there

Register the tongs as an object in stage ①, not as an actor, because they are picked up before they are used. In stage ②, auto-fill usually produces both tracks; the tool track is indented with └ under the others. If it is missing, add it with ＋ Add track and choose the tongs as the holder.

Note how the two layers get different boundary answers. The hand was already holding the tongs when the clip started, so its reach is unobserved. But the tongs reaching for the bread happens fully on camera, so that layer has all six marks. Answer each layer on its own evidence.

Never

An object may not manipulate whatever is holding it. Bread cannot manipulate the tongs, and the tongs cannot manipulate the hand. The tool rejects cycles like this, but it is worth knowing why: the chain runs one way, from actor outward.

Not everything that touches an object is a tool. Using a spoon to stir is a tool chain. Pouring powder out of a cup is not, because the powder is not being held by the cup in the sense that matters here. The test: would the object move with the tool if you moved the tool?

07Checks and finishing

The Checks panel runs continuously over the whole video, not just the clip you are looking at. It separates two severities.

SeverityMeaning
Must fix The annotation is not usable as it stands: no object chosen, marks out of order, a missing manipulation start, an action with no skill.
Needs review Probably wrong, but you are the judge: a mark landing where the actor is invisible, two episodes claiming the same object at the same time, a normal release with no release frame.

Each issue has Go to the frame, which jumps there, switching clips if needed. If a warning is genuinely fine, Dismiss it; dismissed issues fold into a list you can reopen.

A video counts as finished when every clip has tracks and there are no outstanding must fix issues. Warnings do not block it. The banner at the top of the panel tells you which clip is holding you up.

08Pitfalls

Guessing a frame you did not see

Said once at the top and again here because it is the one that damages the data. Use the boundary options. An honest "never filmed" is a usable label; an invented frame number is a silent error that nothing downstream can detect.

Deleting a clip to fix its boundaries

Deleting a clip deletes every entity registered inside it, their masks on disk, and any action annotation for that clip. The confirmation dialog counts exactly what will go. Read it. There is no undo.

Forgetting to merge across clips

If the same hand stays three separate identities, the dataset loses the fact that it was one hand throughout. The reminder when you enter stage ② lists same-named entities that are still separate, but it can only see names, so keep them consistent.

Chasing every tracking wobble

Masks do not need to be pixel-perfect. They need to be the right object, present in the frames where it matters, and not bleeding into a neighbour. A slightly ragged edge costs nothing; a mask that has jumped onto the wrong object ruins the episode built on it.

Making one giant episode

One episode is one continuous hold of one object. If the hand lets go and picks the thing up again, that is two episodes, even if the purpose is the same. Splitting inside a hold is what actions are for.
